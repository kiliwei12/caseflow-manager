本地私有安装

真实案件数据仅保存在你的电脑中
下载项目 ZIP
推荐用于真实业务

本地版与公开 Demo 完全分离

公开 Demo 只提供匿名临时数据；本地版使用电脑中的 SQLite 数据库，不会把案件、客户或跟进记录发送到 CaseFlow 服务器。

🔒 本地数据路径caseflow-manager/data/caseflow.db备份这个文件即可迁移全部数据。
macOS / Linux
  1. 下载并解压项目 ZIP
  2. 双击 CaseFlow.command
  3. 首次运行会自动完成安装
bash install_local.sh
bash start_local.sh
Windows
  1. 下载并解压项目 ZIP
  2. 双击 CaseFlow.bat
  3. 首次运行会自动完成安装
powershell -ExecutionPolicy Bypass -File install_local.ps1
powershell -ExecutionPolicy Bypass -File start_local.ps1

使用说明

  • 需要 Python 3.9 或更高版本。
  • 启动后浏览器访问电脑本机的 CaseFlow 页面。
  • 不要将包含真实资料的 data/ 文件夹上传到 GitHub。
  • 关闭终端中的服务不会删除数据，下次启动仍会保留。
